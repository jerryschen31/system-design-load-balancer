# system-design-load-balancer
Building a Load Balancer to learn about System Design

I'm an old-school computer engineering major from Caltech over 20 years ago, and switched fields into computational genomics / bioinformatics for my Ph.D. and industry career.

With the advent of AI agents, I've decided to devote the 2nd half of my career to developing AI agents and building AI agent infrastructure - always with safety and human-at-the-helm as a non-negotiable.

Inevitably, for any AI engineering position I will be tested on my System Design skills. I am preparing for System Design interview questions by starting with the fundamentals / first-principles, and working my way up the stack.

In this repo, I want to create a Load Balancer service using Go. The end result of creating a load balancer is not the goal. The goal is to use this exercise to learn about aspects of System Design. I will of course use AI coding agents to help write code, but I don't want the agents to just "do the work for me" - that would defeat the purpose. I want the AI agents to teach me fundamental principles and design considerations as we go along, at each step of the implementation process. The agent should assume I am more of an "applied" software engineer within the Biotech domain, who installs and uses cloud infrastructure and applications daily, but lacks experience with building real software systems at scale.
